# issue.fund identity

The logo pairs an open issue circle with an upward check/merge gesture and a detached square dot. It represents work moving from an open issue to a funded resolution.

The standalone mark is `mark.png`. The header combines it with live `issue.fund` text in the existing Space Grotesk typeface for sharp, accessible lettering. The same mark is used as the browser icon.

The original mark was generated with the built-in image-generation tool. It is separate from Decentral Park's upstream tree logo, which remains in the footer.

## Generation prompt

```
Use case: logo-brand.
Asset type: production logo symbol for issue.fund, an open-source GitHub issue bounty platform. This asset will be used at 36 pixels high in the website header and as the favicon.
Design one distinctive, beautifully balanced compact mark: an open issue circle whose right-hand stroke resolves into a confident upward check/merge shape. A small detached square dot at the upper right completes the silhouette, suggesting an issue moving toward a funded resolution. Make the geometry bold and purposeful with optically consistent heavy strokes, a few subtle squared corners, and a generous clear negative-space center. It should feel like a polished contemporary open-source developer brand, understated and memorable.
Color palette: solid deep leaf green #14803D only. Flat opaque shapes, sharp clean edges. True transparent background, preserve alpha. No white background.
Composition: exactly one isolated logo mark, square canvas, tightly framed with 6% equal transparent padding on all sides. Strong at favicon size; no fine details.
Constraints: symbol only, NO letters, NO words, NO wordmark, NO mockup, NO labels, NO gradients, NO shadows, NO 3D, NO textures, NO coin, NO currency sign, NO existing brand logos, NO board of alternatives. Deliver the actual standalone usable transparent logo asset.
```
